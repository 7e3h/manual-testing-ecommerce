## 2. Observed Behavior
When searching for products using special characters or test script strings (e.g. `<script>alert("XSS")</script>`), the network request returns an unhandled HTTP `500 Internal Server Error`, and the product catalog grid renders a blank white area instead of displaying a user-friendly "No products found" message.

---

## 3. Preconditions
1. User is on the Home / Products catalog page (`/`).
2. Search input field is visible and enabled.

---

## 4. Steps to Reproduce
1. Navigate to the Products page.
2. In the search input field, enter:
   ```text
   <script>alert("XSS")</script>
   ```
3. Click the Search button or press Enter.
4. Inspect the UI display and open Browser DevTools (Network and Console tabs).

---

## 5. Expected Result
- The search query is safely handled client-side and server-side.
- The backend returns an HTTP `200 OK` with an empty result set: `{ "data": [], "total": 0 }`.
- The UI displays a clear empty state message: *"There are no products found."*

---

## 6. Actual Result
- The search request fails with HTTP `500 Internal Server Error` on the network request.
- The catalog container empties and displays a blank white section.
- An unhandled `HttpErrorResponse` appears in the browser console.

---

## 7. Observed Diagnostics (Browser DevTools)

### DevTools Network & Console:
- **Request URL:** `GET /api/products/search?q=%3Cscript%3Ealert(%22XSS%22)%3C%2Fscript%3E`
- **Response Status:** `500 Internal Server Error`
- **Console Message:** `ERROR HttpErrorResponse: Http failure response for /products/search: 500 Internal Server Error`

---

## 8. Possible Root Cause (Preliminary Investigation)
The backend search service may be unequipped to handle non-alphanumeric or unescaped query parameters, resulting in an unhandled exception rather than returning an empty match set. On the frontend, the catalog component appears to lack an error-catch block to display the fallback empty state when a 500-series status code is received. Further investigation by the development team is recommended.
